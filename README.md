# .github

Organization-wide GitHub configuration for SCAR-OS: the public org profile
(`profile/README.md`), contribution guidelines, security policy, and
default community health files inherited by repos that don't define their
own.

See [SCAR-OS/SCAR-OS](https://github.com/SCAR-OS/SCAR-OS) for the
implementation and [SCAR-OS/scar-os-docs](https://github.com/SCAR-OS/scar-os-docs)
for research and specifications.
